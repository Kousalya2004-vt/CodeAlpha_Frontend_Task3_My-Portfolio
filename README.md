# Personal Portfolio Website

## 📌 About the Project

This project is a personal portfolio website developed using HTML, CSS, and JavaScript. It showcases my profile, technical skills, projects, resume, and contact information in a clean and responsive design.

## 🚀 Features

- **Home:** Introduction and welcome section.
- **About Me:** Brief personal and professional introduction.
- **Skills:** Displays technical skills and technologies.
- **Projects:** Showcases my projects and work.
- **Resume:** Option to upload and preview a resume PDF.
- **Profile Photo:** Option to upload a profile picture.
- **Contact:** Includes email, LinkedIn, and GitHub links.
- **Responsive Design:** Works across different screen sizes.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Ensure all files and images are in the correct locations.
4. Open `index.html` in your browser or use the Live Server extension.
5. Explore the sections and try the available features.
